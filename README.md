# HR Analytics Dashboard

## Project Overview
**HR Analytics Dashboard: Employee Attrition, Salary & Workforce Insights**

This project analyzes employee workforce data using **Power BI, Excel/CSV, DAX and SQL**. The objective is to identify employee attrition patterns, salary distribution, workforce demographics, department trends and work-mode patterns.

## Tools & Technologies
- Power BI
- Microsoft Excel / CSV
- DAX
- SQL
- GitHub

## Dataset
The dataset contains **30 employee records** with information including:
- Employee ID and name
- Gender and age
- Department and job role
- Education and experience
- Salary and performance rating
- Overtime
- Marital status
- Work mode
- Joining date
- Attrition status

## Key KPIs
- Total Employees: **30**
- Employees Left: **9**
- Active Employees: **21**
- Attrition Rate: **30%**

## Dashboard Pages
1. HR Overview
2. Employee Attrition Analysis
3. Salary Analysis
4. Department Performance
5. Gender Diversity
6. Employee Demographics

## Key Insights from the Sample
- 9 of 30 employees are marked as having left, giving a 30% attrition rate.
- In this sample, most leavers are in the 0–2 years experience group.
- Remote employees have the highest observed attrition rate in this sample; this is an observed association, not proof that work mode causes attrition.
- Salary generally increases with experience in this sample.
- The dataset contains employees across IT, HR, Sales, Finance and Marketing.

## How to Use
1. Import `HR_Analytics_Dataset.csv` into Power BI.
2. Create the DAX measures from `DAX_Measures.txt`.
3. Build the dashboard using the recommended visuals.
4. Add screenshots to the `screenshots` folder.
5. Upload the entire folder to GitHub.
